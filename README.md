# shellscript-project-


### Linux System Administration Automation Using Bash Shell Scripting

**Technologies:** Linux, Bash, Ubuntu, AWK, APT, Linux System Commands.

- Developed an interactive Bash automation script to simplify common Linux system administration tasks through a menu-driven interface.
- Automated Linux user creation by checking existing users, creating new accounts, and configuring user passwords.
- Implemented file and directory backup automation using shell commands, conditional statements, and file operations.
- Automated software installation by checking tool availability and installing missing packages using the APT package manager.
- Integrated disk usage monitoring using `df`, `awk`, and command substitution to retrieve system storage information.
- Used Bash functions, loops, conditional statements, and case statements to build a reusable and interactive administration utility.
